### About me

I build backend services, bots and automation that solve concrete problems. My main stack is **Java with Spring Boot**, backed by PostgreSQL and Redis. I also work with **React and TypeScript** when a project needs a clean web interface, and with **Python** for desktop automation and computer vision.

- 🔧 I care about maintainable architecture, clear interfaces and useful documentation.
- 🤖 I build Discord integrations, moderation workflows and task automation.
- 🏍️ Away from the keyboard, you'll usually find me around motorcycles.
